# design.md

> 모서리의 시각 규격. 기획서(`독서기록-기획서.md`)와 함께 봅니다.
> 여기 적힌 값은 시안에서 역산한 것이므로 **그대로 씁니다.** 임의로 조정하지 마세요.

---

## 원칙

1. **순백과 순검정을 쓰지 않습니다.** 종이색과 먹색만 씁니다.
2. **표지는 주인공이 아닙니다.** 원본이 200px뿐이라 크게 쓸 수 없고,
   그래서 타이포그래피와 색이 화면을 이끕니다.
3. **손으로 그은 선이 이 앱의 서명입니다.** 자로 그은 직선을 쓰지 않습니다.
4. **정연한 격자 위에서만 불규칙을 허용합니다.** 들쭉날쭉함은 책의 실물에서
   나올 때만 의미가 있습니다.

## 색

| 이름 | 값        | 쓰임                                   |
| ---- | --------- | -------------------------------------- |
| 종이 | `#F7F4ED` | 페이지 배경                            |
| 카드 | `#FFFDF8` | 흰 카드가 필요할 때                    |
| 먹   | `#23211D` | 본문, 활성 상태                        |
| 보조 | `#6B665C` | 출처, 저자, 날짜, 비활성               |
| 선   | `#DDD8CC` | 1px 구분선, 테두리                     |
| 밑줄 | `#57544D` | 손으로 그은 밑줄                       |
| 강조 | `#C4573A` | **역할 미정. 지정 전까지 쓰지 마세요** |

### 책별 색 (`accent_color`)

표지에서 대표색을 뽑아 **반드시 정규화**한 뒤 씁니다.

```
HSL 변환 → 명도 88~91%, 채도 15~30%로 클램프
```

정규화 없이 쓰면 어떤 책은 새까맣고 어떤 책은 형광입니다.
명도 상한을 93%가 아니라 91%로 두는 이유는, 그보다 밝으면 종이색과
구분이 안 되기 때문입니다.

검증된 예시: `#E8EDE4` `#EDE6DC` `#E2E7EE`

## 레이아웃

- 컨테이너 폭 **720px**, 좌우 안쪽 여백 **28px** (= 안쪽 664px)
- **모든 화면이 같은 폭을 씁니다.** 책장과 밑줄을 오갈 때 틀이 흔들리면 안 됩니다.
- 상단 네비 높이 52px, 아래에 1px 선
- 모바일은 컨테이너 폭 100%, 좌우 여백 20px

### 표지 격자 (책장)

```
grid-template-columns: repeat(4, 148px);
column-gap: 24px;
row-gap: 36px;
```

- 셀 안에 높이 **176px**의 슬롯을 두고, 표지를 **아래 기준선에 맞춰** 놓습니다.
- 표지 크기 계산:
  ```
  높이 = size_height(mm) × 0.7
  폭   = 높이 × (표지 이미지의 실제 가로/세로 비)
  폭이 148px를 넘으면 폭 기준으로 다시 축소
  ```
- **높이는 판형이 정하고, 모양은 이미지가 정합니다.** 슬롯 비율을 판형으로
  잡아버리면 이미지 비율과 어긋나 늘어나거나 잘립니다.
- 판형 데이터가 없으면 152 × 225mm로 계산합니다.
- 표지 아래 12px 띄우고 제목 → 2px → 저자 → 3px → 밑줄 개수.

## 손으로 그은 선

이 앱의 서명입니다. 세 곳에 씁니다: 문장 카드의 구분선, 상단 네비의 활성 표시,
그리고 저장 완료 같은 순간의 반응.

```
stroke: #57544D (네비는 #23211D)
stroke-width: 2
stroke-linecap: round
vector-effect: non-scaling-stroke
```

- **매번 다른 파형을 그립니다.** 같은 path를 재사용하면 손으로 그은 게 아니라
  도장을 찍은 것처럼 보입니다.
- 대상의 id를 시드로 삼아 결정적으로 생성합니다. 같은 문장은 언제 봐도 같은 선이어야
  합니다.
- 흔드는 폭: 제어점 y를 ±2px, 시작·끝점을 ±3px 정도. 그 이상은 장난스러워집니다.
- 폭이 바뀌어도 굴곡 비율과 선 굵기가 유지되어야 합니다. 요소 폭을 재서
  path를 생성하는 방식이 안전합니다.

### 문장 카드의 밑줄

문장 전체에 긋지 않습니다. **문장과 출처를 가르는 구분선 자리**에 놓습니다.
문장 전체에 그으면 여러 줄일 때 선이 여러 개가 되고, 마지막 줄이 짧으면
어중간하게 끊깁니다. 이 자리에 두면 카드당 선이 정확히 하나입니다.

문장 아래 7px, 높이 12px.

## 컴포넌트

### 문장 카드

- 배경: 그 책의 `accent_color`
- 안쪽 여백: `32px 30px 26px`
- 모서리 둥글리지 않습니다
- 구성: 문장 → (7px) → 손으로 그은 선 → (18px) → 출처와 쪽수(양끝 정렬)
  → 코멘트가 있으면 (24px) → 코멘트 → (4px) → 날짜
- **코멘트는 출처와 다른 층입니다.** 여백을 충분히 주거나 왼쪽에 짧은 세로선을
  두어 구분합니다. 코멘트가 여러 개 쌓일 것을 전제로 만듭니다.
- 카드 사이 간격 **28px**. 이보다 좁으면 색 블록이 이어진 띠처럼 보입니다.

### 오늘의 밑줄

문장 카드와 같은 형태에 위에 섹션 라벨을 얹은 것.
안쪽 여백 `34px 32px 28px`, 문장 22px.
배경은 **그 문장이 속한 책의 `accent_color`**입니다. 고정색이 아닙니다.

### 상태 탭

수평 나열, 간격 22px. 각 항목은 `이름 + 개수`.
활성은 굵기 600에 먹색, 비활성은 400에 보조색. 밑줄이나 배경으로 표시하지 않습니다.

### 아이콘

상단 네비의 섞기와 검색, 둘뿐입니다. `stroke-width: 1.6~1.8`, 크기 16px.
아이콘을 늘리지 마세요.

## 모션

- 문장 카드가 나타날 때 밑줄이 그어집니다. **0.7초, ease-out.**
  `stroke-dashoffset`을 애니메이션합니다.
- 카드가 여러 장 나타날 때는 순차로, 카드당 0.08초 지연.
- 상태가 '읽음'으로 바뀌는 순간, 첫 별점을 매기는 순간에도 짧은 반응을 줍니다.
- 전부 `@media (prefers-reduced-motion: no-preference)`로 감쌉니다.
