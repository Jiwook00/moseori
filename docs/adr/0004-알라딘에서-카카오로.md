# 0004 — 책 데이터 출처를 알라딘에서 카카오로

상태: 채택 (2026-09-17). 쪽수·판형 보조(국립중앙도서관 seoji)는 적용 (이슈 #7, 2026-09-21).

## 맥락

기획서 §4·§7은 알라딘 TTB API를 전제로 짜여 있었다. 알라딘 API가 서비스를 종료한다.
대안인 카카오 책 검색(Daum 검색)은 필드가 훨씬 적다.

| 알라딘에서 쓰던 것            | 카카오                                        |
| ----------------------------- | --------------------------------------------- |
| `itemId` (book 자연키)        | 없음                                          |
| `subInfo.itemPage` (쪽수)     | 없음                                          |
| `subInfo.packing` (판형·무게) | 없음                                          |
| `cover` 200px → `/cover500/`  | `thumbnail` 120×174 고정, `fname`에 원본 주소 |
| `author` 역할 붙은 원문       | `authors[]` · `translators[]` 배열            |
| `description`                 | `contents` — 잘린 발췌, HTML 이스케이프됨     |

## 결정

- **자연키를 `isbn13`으로.** `aladin_item_id`는 nullable로 남긴다 (옛 책의 raw·표지 경로).
  ISBN13이 없는 책은 검색 결과에서 뺀다. 적용 시점 22권 전부 ISBN13이 있고 중복 없음.
- **호출은 한 번.** 담을 때 `target=isbn`으로 다시 조회한다 (검색 응답을 클라이언트에서
  믿지 않기 위해).
- **큰 표지는 `fname`의 원본.** 표본 15권 전부 폭 425~458px. 실패하면 썸네일로 폴백하고
  300px 판정·`cover_is_large`는 그대로 쓴다.
- **저자는 `"이름 (지은이), 이름 (옮긴이)"`로 조립한다.** 옛 원문과 표기를 맞춰
  `authorName`이 그대로 동작하게. 카카오 `authors`에는 역할이 없어 전부 지은이로 적는다.
- **쪽수·판형은 국립중앙도서관 ISBN 서지정보 API(`/seoji/SearchApi.do`)로 보조한다**
  (사용자 결정). `BOOK_SIZE`는 `"183*235"` — 이미 mm, `폭*세로`라 **세로(둘째 숫자)만**
  `size_height`에 쓴다(cm 아님). §5가 "높이만 판형에서, 폭은 이미지 비율로" 계산하므로
  격자 규칙이 성립한다. 실측 채움률 ~50%(표본 22권)라 **보조일 뿐, 실패해도 담기를 막지 않는다.**
  소장자료 검색(`search.do`)은 쪽수·크기를 주지 않아 쓰지 않는다.
- 알라딘 코드와 `ALADIN_TTB_KEY`는 지운다.

## 결과

- 새로 담는 책은 seoji가 주면 쪽수·세로가 채워지고, 결측(~절반)이면 쪽수 없이 판형은 기본값 152×225다.
- 알라딘 시절 책은 판형·무게·제본이 그대로 남고, 새 책은 무게·두께·제본이 계속 비어 있다.
- §5의 "가로·세로 뒤바뀜 보정"은 알라딘 데이터에 대한 규칙으로 남는다.
