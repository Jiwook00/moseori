# 0001 — 폭을 통일하지 않는다 (읽기 폭 720 / 컨테이너 화면 폭)

상태: 채택 (2026-08-05)

## 맥락

처음엔 모든 화면을 720px 고정 · 가운데 정렬로 잡았다. 넓은 모니터에서
상세와 밑줄 목록이 **가운데 좁은 기둥**으로 붕 떠 보였다.

## 결정

폭을 하나로 통일하지 않는다. **컨테이너는 화면 폭**을 쓰고, **720px는 글줄
(문장·리뷰)에만** 건다. 색·배경 같은 면은 화면 폭이다.

- 밑줄 목록: accent 카드(720)를 **왼쪽 거터 정렬**. 가운데가 아니라 왼쪽에
  붙어 넓은 화면에선 오른쪽에 종이가 남는다.
- 책 상세: `lg`↑에서 **펼침 2단** — 왼쪽 종이(책·리뷰) `sticky` / 오른쪽 밑줄
  accent **필드**가 화면 오른쪽 끝까지. 비율 4:6.
- 책장: 화면 폭 갤러리, 최대 4열.
- 네비: 전체 폭. 같은 왼쪽 거터(`px-5 sm:px-7`)로 화면들의 왼쪽 모서리를 잇는다.

현행 규격의 정본은 `design.md` §레이아웃·§책 상세다. 여기엔 "왜 뒤집었나"만 둔다.

## 결과

- 색 면이 화면 폭을 쓰므로 초광폭에서 색 면이 과다할 수 있다 — 실사용에서 판단.
- 네비(전체 폭)와 720 글줄의 왼쪽 정렬 어긋남이 거슬리는지 확인이 남았다.
