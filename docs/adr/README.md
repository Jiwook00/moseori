# ADR — 결정 기록

기획서나 `design.md`의 **확정을 뒤집은 구조적 결정**만 여기 적습니다.
"이렇게 만들었다"는 ADR감이 아닙니다 — 그건 코드와 `git log`에 있습니다.
"명세엔 X인데 우리는 Y로 갔고, 그 이유는—"인 것만 남깁니다.
